# 计算机网络演示讲义：TCP 三次握手

本讲义是 CampusClaw 的演示资料，用于展示课程知识检索。

## 建立连接的顺序

TCP 建立连接时，客户端先发送带 SYN 标志的报文；服务器收到后回复带 SYN 和 ACK 标志的报文；客户端再发送带 ACK 标志的报文。这个顺序通常称为“三次握手”。

## 为什么需要确认

握手过程让两端确认对方能够收发报文，并交换各自的初始序列号。收到第三次 ACK 后，服务器才确认客户端收到了自己的 SYN。

## 与数据传输的关系

三次握手用于建立连接，不等同于应用层的账号登录。连接建立后，应用才可以在 TCP 连接上发送 HTTP 请求。
