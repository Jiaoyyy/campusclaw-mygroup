# 个人 AI 应用平台与请求验证报告

## Why

个人作业要求多个内置 AI 应用、提示词模板、知识库检索、内置及上传 Skill、外部工具和 MCP，并核对真实 LLM 请求、响应与执行逻辑。原平台已有检索、技能文件、智能体和 MCP，需要补齐默认应用与模板，并提供可复现证据。

## What Changes

- 每个班级初始化三个独立应用与三个完整 Markdown 技能，不覆盖教师已有修改。
- 增加登录可访问的提示词模板目录和教师模板选择入口。
- 用独立 Compose 项目和合成资料记录真实对话网关及本地 MCP 协议请求，生成最终 PDF。

## Boundaries

Skill 为提示词驱动的教学规则文件，不执行上传文件中的程序。MCP 首版保持单个服务和每轮最多一个只读工具；模板为可编辑的完整角色文本。
