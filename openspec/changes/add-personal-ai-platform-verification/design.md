# Design

`internal/aicatalog` 是应用、模板和内置 Markdown 的唯一目录；数据库初始化按班级和名称查询，只补建缺失记录。已有应用与绑定不被重写。模板 API 返回可复制编辑的完整提示词，前端选择后填入现有角色提示词字段。

验证不增加生产日志。独立 API 的对话和 MCP 地址临时指向本地转发记录器；记录器保留请求和响应正文，不保存 Authorization 或 Cookie。对话请求仍通过真实课程网关，MCP 使用仓内公开术语演示服务。验证材料全部人工构造，以文件尾部标记和技能尾部标记核对“全部内容是否发送”。

PDF 引用具体证据、源码位置和验证环境。真实返回与参数示例明确区分；不得将模拟返回写成真实模型回答。
