# 检索与问答试用材料

以下六份文件是**功能演示材料**，已由 `teacher_a` 上传到 A 班知识库。前三份是虚构的流程和清单，不代表真实校规或课程作业要求；后三份是常见计算机课程知识点。A 班教师和学生可以在材料列表看到它们；B 班账号不能查看。

| 演示文件 | 可以输入的问题 | 回答中应能核对的事实 |
| --- | --- | --- |
| `演示-图书馆借阅规则.md` | 图书馆的普通图书能借多久，可以续借几次？ | 借阅 14 个自然日；每册最多续借 1 次。 |
| `演示-实验室安全流程.md` | 实验室洒出液体时应该怎么办？ | 停止操作、提醒附近人员、通知值班教师；不要徒手清理。 |
| `演示-课程项目提交清单.md` | 晨星项目要提交哪些内容？ | 源码仓库链接、运行说明 README、两张功能截图。 |
| `演示-数据结构-二叉搜索树.md` | 二叉搜索树中序遍历的结果是什么顺序？ | 从小到大排列的键。 |
| `演示-计算机网络-TCP三次握手.md` | TCP 三次握手的三个报文顺序是什么？ | 客户端 SYN、服务器 SYN+ACK、客户端 ACK。 |
| `演示-数据库-事务ACID.md` | 事务原子性和持久性有什么区别？ | 原子性避免事务部分执行；持久性保证提交结果可在故障后恢复。 |

打开本地 `http://127.0.0.1:18082/materials`，使用 A 班账号登录并刷新页面。在“本班知识库检索”中输入表中的问题，分别选择“关键词”“向量”“混合”后点击“检索”，查看命中的文件名和原文摘录。再点击“简短回答”，核对回答中的 `[1]` 等编号与下方出处；点击出处可以打开对应原文。不同检索方式的排序或命中数量可以不同，不应把回答当成真实政策。

课程网关配置只保存在本地 Git 忽略的 `.env`；对话模型为 `course-chat`，嵌入模型为 `course-embedding`。不要在截图或仓库中展示网关 Key。
